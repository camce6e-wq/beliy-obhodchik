# БелыйОбходчик — Инструкция по использованию

## Как получить рабочий конфиг (за 5 шагов)

1. **Нажмите `/buy` в боте [@beliy_obhodchik_bot](https://t.me/beliy_obhodchik_bot)**
   - Если у вас есть оплаченные заказы — бот предложит обновить существующий или создать новый.

2. **Укажите IP вашего VPS**
   - Введите публичный IP вашего VPS (например: `203.0.113.10`)
   - Бот автоматически подберёт лучший рабочий SNI-донор (маскировку трафика)

3. **Оплатите**
   - Кнопка «💳 Оплатить 500 ₽ (Crypto Bot)» — оплата в USDT через Crypto Bot
   - Кнопка «⭐ Оплатить X звёздами» — оплата звёздами Telegram (XTR)

4. **Выберите способ установки Xray на VPS**
   После оплаты бот покажет два варианта:

   ### Вариант А. Авто-установка по SSH (проще всего)
   - Нажмите «🔑 Авто-установка по SSH»
   - Пришлите пароль `root` от вашего VPS одной строкой
   - Бот подключится к VPS, скачает `setup_vps.sh`, установит Xray (Reality), сгенерирует настоящие ключи и сразу соберёт конфиг

   **Если бот пишет «Не удалось авторизоваться по SSH»**
   - На некоторых VPS (Ubuntu cloud-init) вход root по паролю отключён. Выполните на сервере 3 команды и нажмите «🔁 Я всё включил — попробуй ещё раз»:

   ```bash
   sudo sed -i 's/^#*PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
   sudo sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication yes/' /etc/ssh/sshd_config
   sudo systemctl restart ssh
   ```

   ### Вариант Б. Сам запущу скрипт (надёжнее, без передачи пароля боту)
   - Нажмите «🔧 Сам запущу скрипт»
   - Бот пришлёт архив с `setup_vps.sh`
   - Скачайте файл на VPS, выполните:
   
   ```bash
   chmod +x setup_vps.sh
   sudo SNI_HOSTNAME=<донор> bash setup_vps.sh
   # или с IP донора
   sudo SNI_HOSTNAME=<донор> SNI_IP=<ip> bash setup_vps.sh
   ```
   
   - Скопируйте **весь** вывод от `===BELIY-OBHODCHIK-VLESS===` до `===END===` и пришлите его боту целиком — конфиг будет доставлен автоматически

5. **Скачайте конфиг**
   - Бот пришлёт ZIP-архив с готовой конфигурацией для Keenetic + инструкцией + правилами HydraRoute + скриптом проверки обновлений
   - Распакуйте архив и следуйте `README.txt`

## Полезные команды

- `/start` — приветствие и краткая информация
- `/buy` — начать покупку/обновление конфига
- `/myorders` — список ваших заказов
- `/status` — состояние системы (SNI-доноры)
- `/guide` — эта инструкция
- `/help` — справка

## Полезные советы

- **Повторная покупка**: если у вас уже есть оплаченный заказ — `/buy` предложит «Обновить существующий заказ». При обновлении бот подберёт новый лучший SNI-донор, сохранит ключи VPS (не трогая Xray) и пришлёт новый конфиг.
- **Безопасность SSH**: после успешной авто-установки (Вариант А) можно вернуть `PermitRootLogin prohibit-password` обратно — бот не хранит пароль после завершения установки.
- **SNI-донор**: бот автоматически выбирает рабочий донор с лучшей успешностью. При блокировках можно обновить заказ, получив новый донор.
