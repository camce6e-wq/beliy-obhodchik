# KNOWN_ISSUES

Известные ограничения и «потолки» текущих реализаций. Если пункт перестал быть
актуален — удали его отсюда и отметь в CHANGELOG.

## Функциональные

1. **Оплата звёздами (XTR) не имеет рефандов.** После оплаты звёзд возврат
   средств возможен только вручную (Telegram не предоставляет API-рефанд для
   ботов). Это осознанное ограничение платформы, не баг кода.

2. **Бот поддержки пересылает вопросы владельцу** и раздаёт готовые ответы по
   шаблонам; живой оператор не в чате 24/7. Ограничение бизнес-модели.

3. **Пагинация `/myorders` и меню «обновить заказ» — текстовые, без
   inline-навигации.** Список режется на части по 5 и кнопки по 6 со «Показать
   ещё» — этого достаточно для реальных объёмов; интерактивные страницы
   добавлять только при жалобах на длину.
   *Upgrade:* inline-клавиатура с «◀️ ▶️».

## Технические

4. **Закрыто (4f8d693).** Серверная верификация оплаты на VPS (`payment_verify.py`):
   сумма и проверка txid на сервере, выдача только после серверного подтверждения.
   API доступен через Cloudflare Tunnel (HTTPS). Клиентский гейт `localStorage.bo_paid`
   больше не обязателен. *Остаётся:* домен + Let's Encrypt вместо временного туннеля.

5. **Нет полноценного typecheck/linter со стилем** — в CI работает
   `ruff --select E9,F` (синтаксис, неопределённые имена, неиспользуемые
   импорты/переменные); стиль (длина строк, именование) не проверяется
   (см. ASSUMPTIONS #1–2). Типизация — отдельная инициатива.

6. **Две рабочие копии сайта** (Default Project и репозиторий) могут разойтись,
   если править файлы вне `deploy_site.ps1`. Проверено 2026-09-27: идентичны;
   в деплой-скрипт добавлено предупреждение при рассинхроне.
   *Upgrade:* единственный источник + `git diff`-гайд в деплое.

7. **Локальный polling бота невозможен при работающем проде** (`409 Conflict`).
   Для локальной отладки использовать тесты или бота поддержки на другом сервере.

8. **CI-смоук сайта есть, живой смоук бота — по опции.** `.github/workflows/smoke.yml`
   проверяет сайт каждые 6 часов; бот-проверка (getMe) включится сама, как только
   в репозиторий заведут секрет `BOT_TOKEN` (токен основного бота). Пока секрета
   нет — бот проверяется тестовым набором и вручную.
