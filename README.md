# БелыйОбходчик — Автоматическая система настройки Keenetic

## 🚀 Автоматизированный бизнес без твоего участия

Система для автоматической настройки VLESS Reality на Keenetic роутерах. Пользователь платит 500 ₽ → получает готовый конфиг → интернет работает.

## 📁 Структура проекта

```
sni-database/
├── landing_index.html          # Лендинг для приёма заказов
├── telegram_bot.py            # Автоматический Telegram-бот
├── vps_installer.py           # Установщик на VPS пользователя
├── keenetic_config_generator.py # Генератор конфигов для Keenetic
├── sni_manager.py             # База SNI-доноров с автосканированием
├── database_schema.sql        # Схема базы данных
├── requirements.txt           # Зависимости Python
└── README.md                  # Эта инструкция
```

## ⚡ Быстрый старт

### Шаг 1: Запустить сайт (бесплатно на GitHub Pages)

1. Создай репозиторий на GitHub
2. Загрузи все файлы из этой папки
3. Включи GitHub Pages в настройках репозитория:
   - Settings → Pages → Source: `main` branch → Save
4. Сайт будет доступен по адресу:
   ```
   https://твой-логин.github.io/название-репозитория/
   ```

### Шаг 2: Создать Telegram-бота

1. Открой [@BotFather](https://t.me/botfather) в Telegram
2. Создай нового бота командой `/newbot`
3. Скопируй токен (пример: `1234567890:ABCDEFGhijKLMNopQRSTuvwXYZ`)
4. Установи зависимости:
   ```bash
   pip install pyTelegramBotAPI
   ```
5. Запусти бота:
   ```bash
   # Windows
   set TELEGRAM_BOT_TOKEN=твой_токен
   python telegram_bot.py
   
   # Linux/Mac
   export TELEGRAM_BOT_TOKEN=твой_токен
   python telegram_bot.py
   ```

### Шаг 3: Настроить платёжную систему

В файле `telegram_bot.py` замени фейковую оплату на реальную:

```python

# - ЮKassa (для РФ)
# - Stripe (международные)

```

## 💰 Как работает монетизация

### Для пользователя:
1. Видит сайт → понимает решение за 30 секунд
2. Пишет боту `/buy` → вводит IP своего VPS
3. Оплачивает 500 ₽ → получает архив с конфигами
4. Загружает в роутер → интернет работает

### Для тебя:
- **Нулевые расходы**: нет серверов, нет инфраструктуры
- **Полная автоматизация**: бот всё делает сам
- **Пассивный доход**: система работает 24/7

## 🔧 Технические компоненты

### 1. База SNI-доноров (`sni_manager.py`)
- Автоматическое сканирование работающих доноров
- Рейтинговая система (успешность, скорость, стабильность)
- Ежедневное обновление базы

### 2. Установщик VPS (`vps_installer.py`)
- Полностью автоматическая настройка VLESS Reality
- Генерация уникальных ключей для каждого пользователя
- Создание конфигов для Keenetic

### 3. Генератор конфигов (`keenetic_config_generator.py`)
- Конфиги для Xray и Sing-box
- Правила HydraRoute для раздельной маршрутизации
- Полные инструкции для пользователя

### 4. Telegram-бот (`telegram_bot.py`)
- Приём заказов и оплаты
- Автоматическая генерация конфигов
- Поддержка пользователей
- Статистика и мониторинг
