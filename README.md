# БелыйОбходчик — Автоматическая система настройки Keenetic

## 🚀 Автоматизированный бизнес без твоего участия

Система для автоматической настройки VLESS Reality на Keenetic роутерах. Пользователь платит за настройку (1500 ₽ или 750 ⭐; услуга «обход DPI без сервера» — 1000 ₽ или 500 ⭐) → получает готовый конфиг → интернет работает.

## ⚡ Быстрый старт

### Шаг 1: Запустить сайт (бесплатно на GitHub Pages)

1. Создай репозиторий на GitHub
2. Загрузи все файлы из этой папки
3. Включи GitHub Pages в настройках репозитория:
   - Settings → Pages → Source: `main` branch → Save
4. Сайт будет доступен по адресу:
   ```
   https://твой-логин.github.io/название-репозитория/
   ```

### Шаг 2: Создать Telegram-бота

1. Открой [@BotFather](https://t.me/botfather) в Telegram
2. Создай нового бота командой `/newbot`
3. Скопируй токен (пример: `1234567890:ABCDEFGhijKLMNopQRSTuvwXYZ`)
4. Скопируй пример настроек и заполни токены (`TELEGRAM_BOT_TOKEN`,
   `CRYPTOPAY_TOKEN`, `ADMIN_USER_IDS`):
   ```bash
   cp .env.example .env
   ```
5. Установи зависимости и запусти бота:
   ```bash
   pip install -r requirements.txt

   # Windows
   run_prod_bot.bat            # читает .env

   # Linux
   python telegram_bot.py      # токены из .env
   ```

### Шаг 3: Настроить платёжную систему

Оплата уже интегрирована в `telegram_bot.py` и работает через:

- **Crypto Bot (Crypto Pay)** — счёт в USDT на 1500 ₽, статус оплаты проверяется автоматически
- **Звёзды Telegram (XTR)** — нативный инвойс, конфиг выдаётся сразу после оплаты

Секреты задаются через `.env` (см. `.env.example`):

```
TELEGRAM_BOT_TOKEN=токен_от_@BotFather
CRYPTOPAY_TOKEN=токен_приложения_Crypto_Pay
```

Запуск продакшена: `run_prod_bot.bat` (читает `.env`).

### Шаг 3.1: Бот поддержки (опционально)

На сайта и в ответах бота встречается `@beliy_obhodchik_support_bot` — чтобы эта
ссылка вела на живой бот, создайте его в @BotFather (юзернейм
`beliy_obhodchik_support_bot`), впишите токен в `.env` (`SUPPORT_BOT_TOKEN`) и
запустите `run_support_bot.bat` (или сервис `beliy-obhodchik-support.service`).
Вопросы, на которые бот не ответил сам, уходят владельцам из `ADMIN_USER_IDS`;
ответ владельца на пересланное сообщение доставляется пользователю.

## 🔧 Технические компоненты

### 1. База SNI-доноров (`sni_manager.py`)
- Доноры — проверенные домены: `check_donor` честно проверяет TLS-хендшейк + ALPN h2
- Рейтинговая система (успешность, скорость, стабильность)
- Повторный `add_donor` не сбрасывает статистику; CDN-хосты определяются по имени

### 2. Генератор конфигов (`keenetic_config_generator.py`)
- Конфиги для Xray и Sing-box
- Правила HydraRoute для раздельной маршрутизации
- Полные инструкции для пользователя
- Настоящая пара x25519 (публичный ключ уходит в конфиг, приватный остаётся на сервере)

### 3. Telegram-бот (`telegram_bot.py`)
- Приём заказов и оплаты
- Автоматическая генерация конфигов
- Поддержка пользователей
- Статистика и мониторинг

CI (`.github/workflows/tests.yml`, запускается на каждый push) дополнительно делает:
`ruff check --select E9,F`, `py_compile` всех модулей и `sh -n`/`bash -n`
скриптов установки. Отдельный `smoke.yml` каждые 6 часов проверяет живой сайт
(GitHub Pages) и — при наличии секрета `BOT_TOKEN` — токен бота через `getMe`.

### Деплой

- **Сайт** (GitHub Pages): правки делаются в рабочей папке **Default Project**, затем публикация:
  ```powershell
  powershell -ExecutionPolicy Bypass -File ".\deploy_site.ps1" -CommitMsg "feat(site): описание"
  ```
  Скрипт копирует веб-файлы в репозиторий, коммитит и ждёт сборку Pages.
  Живой сайт: https://beliyobhodchik.fun/
- **Бот** (VPS `89.125.68.226`): после любого изменения бота на `main` выполнить
  ```bash
  bash /opt/beliy-obhodchik/deploy/update.sh
  ```
  Скрипт делает `git pull --ff-only` + `pip install -r requirements.txt` + перезапуск
  systemd-сервисов `beliy-obhodchik` и `beliy-obhodchik-support`. Логи:
  `/var/log/beliy-obhodchik/`.

## 🚨 Важные моменты

### Юридические аспекты:
- **Мы не предоставляем VPN-услуги** — пользователь настраивает свой сервер
- **Продаём "автоматизацию настройки"** — это легально

- Доступ в интернет
